# tesladriver3D

Mapa 3D de navegación para el navegador del coche (Tesla) y el móvil. Es una web que se instala como aplicación (PWA).

- Aplicación: https://autoboard-nav.github.io/tesladriver3d/
- Modo autopista 3D: https://autoboard-nav.github.io/tesladriver3d/autopista.html

## Primer uso
La aplicación no trae claves. Al abrirla por primera vez pide las tuyas (gratuitas) y las guarda **solo en tu navegador**:

| Servicio | Para qué | Dónde se consigue |
|---|---|---|
| MapTiler (obligatoria) | Mapa | https://cloud.maptiler.com/account/keys/ |
| TomTom (obligatoria) | Rutas, tráfico, búsqueda | https://my.tomtom.com/keys |
| OpenChargeMap (opcional) | Cargadores | https://openchargemap.org/develop |

Luego se pueden cambiar en Ajustes → 🔑 Mis claves.

## Instalar con Chrome
- **Android**: menú ⋮ → *Instalar aplicación* (o *Añadir a la pantalla de inicio*).
- **Ordenador**: icono de instalar en la barra de direcciones, o menú ⋮ → *Transmitir, guardar y compartir* → *Instalar página como aplicación*.
- **iPhone**: abrir en Safari → Compartir → *Añadir a pantalla de inicio*.
- El navegador del Tesla no instala PWAs: se abre el enlace directamente.

## Datos
Ajustes, favoritos, radares editados y rutas habituales se guardan en el navegador de cada dispositivo. No hay cuenta ni servidor.
